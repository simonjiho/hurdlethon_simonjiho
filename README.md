# hurdlethon_simonjiho

이름과 월 수입을 입력받아 경고창을 띄우는 웹 페이지 한 장이다. 페이지 제목은 "GDG On Campus Sogang"이다. 2024년 11월에 올렸다.

- `test.html`: 이름 입력칸과 `Hello!` 버튼, 월 수입 입력칸과 `확인하기` 버튼이 있는 페이지
- `helloName.js`: 동작을 맡는다
  - 페이지를 열면 `Hello GDG on Campus Sogang!` 경고창이 뜬다
  - `Hello!` 버튼은 입력한 이름으로 같은 형식의 경고창을 띄운다
  - `확인하기` 버튼은 금액에 따라 문구가 다르다. 15,000,000원 초과는 "꿈이 크시군요!", 1,500,000원 초과는 "언젠간 가능할겁니다. 화이팅!", 그 이하는 "지금도 가능하지 않을까요...?"
  - 수입 칸에는 숫자, Backspace, Delete, 좌우 방향키, Tab 키만 입력된다
- `style.css`: 배경과 글자색, 어두운 빨강(`#b22222`) 제목·버튼, 수입 칸 오른쪽 정렬, 숫자 증감 버튼 숨김

## 실행

빌드 없이 `test.html`을 브라우저로 연다.
